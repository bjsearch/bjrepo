## 🚀 사용 방법

### 방법 1: GitHub에서 직접 확인 ⭐ (추천)

1. Repository 열기

3. `보장분석_완전판_[고객명].md` 파일 선택


## 🔧 새로운 고객 추가 (Excel 파일)

### Step 1: Excel 파일 준비
```
구조:
- Row 2: 고객명 (B2)
- Row 3-4: 작성자/작성일 (K3/K4 또는 N3/N4)
- Row 6: 상품명 (각 열이 하나의 상품)
- Row 7-20: 상품 세부정보
- Row 25+: 보장 정보
```

### Step 2: 스크립트 실행

```python
from excel_insurance_analyzer import analyze_insurance_excel

# Excel 분석
data = analyze_insurance_excel("customer.xlsx")

# 고객정보, 상품, 보장정보 자동 추출
customer = data['customer']
products = data['products']
coverage = data['coverage']
```

### Step 3: 리포트 생성

```bash
python generate_complete_reports.py
```

## 📞 문의

### 문제 해결
1. **새로운 Excel 파일이 작동하지 않음**
   - `EXCEL_EXTRACTION_GUIDE.md`의 "파일 구조" 섹션 확인
   - 행 번호 및 키워드 일치 여부 확인

2. **리포트 정보 누락**
   - Excel 파일의 각 행이 제대로 채워져 있는지 확인
   - 공백 셀이 없는지 검증

3. **다른 고객 추가**
   - 같은 구조의 Excel 파일 준비
   - `generate_complete_reports.py` 스크립트 수정 후 실행
